# AI Images Prompt Examples for Social, Product, and Portrait Uses

Good AI image prompt examples teach structure. They show how to describe a subject, scene, lighting, composition, style, and constraints in a way the model can follow.

Use these examples as starting points. For a larger prompt collection, visit [Explore](/explore). For realistic photo examples, read [AI Photo Prompts](/blog/ai-photo-prompts).

## The Example Formula

Use this base structure:

```text
[Subject] in [scene], [lighting], [camera/composition], [style/mood], [detail], avoid [problems].
```

## How to Adapt Any Example

Change only one or two variables first:

- Subject
- Location
- Lighting
- Camera angle
- Color palette
- Constraint

If you change every variable at once, you lose the reason the example worked.

## FAQ

### Can I copy these prompts directly?

Yes, but you will get better results if you adapt subject, setting, and lighting to your goal.

### Why do prompt examples sometimes fail?

Different models interpret style and constraints differently. Treat examples as frameworks, not guarantees.

### How many examples should I test?

Test 5 to 8 directions, choose the strongest, then refine deeply.
